# Peppa Match Game

A small browser-based matching game built as a personal learning project.

The game presents a grid of character cards, tracks player progress, provides sound feedback, and adapts its layout for desktop, tablet, and mobile screens.

## What this project demonstrates

- HTML, CSS, and JavaScript fundamentals
- DOM-based game state and interaction
- Responsive layout design
- Card matching logic
- Audio feedback
- Basic UI animation and game reset behavior

## Project structure

```text
Peppa-Match-Game/
├── index.html
├── Matching-Game/
├── corner-images/
└── sounds/
```

## Run locally

Clone the repository and open `index.html` in a browser. No build step or package installation is required.
